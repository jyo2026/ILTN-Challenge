# ILTN-Challenge
Indian LegalTech Tracker

A small personal dashboard for following the Indian legal tech scene, built while I prep for a Legal Engineer role.

It tracks recent writing from Shreya Vajpei (founder of the Indian LegalTech Network) and posts from ILTN itself, along with a profile of the five judges for the ILTN x vibecode.law Vibeathon 2026, and a leaderboard section for the hackathon submissions.

This isn't connected to any live data source. LinkedIn and most legal tech sites don't offer a way to pull posts automatically, so everything here is added by hand as I come across it. All the content lives in data.js, kept separate from the layout, so updating a post, a judge's bio, or the leaderboard just means editing that one file and pushing.

Built as a static site (HTML, CSS, and vanilla JS), deployed on Vercel. No backend, no build step, no dependencies.

This is a personal project, not affiliated with or endorsed by ILTN, my employer, or any of the people or organizations mentioned. All information is sourced from public posts, articles, and event pages, with links back to the originals wherever possible.
